ИИ-ассистент разбирает сообщения сообщества ВКонтакте

Если вы ведёте сообщество, входящие копятся быстрее, чем на них отвечаешь. VK MCP Server даёт Claude доступ к сообщениям сообщества: он читает непрочитанное, пересказывает и готовит ответы, а отправляет только после вашего «да».

Как это выглядит

Вы пишете ассистенту обычным текстом:

Разбери входящие сообщества. Отвечай дружелюбно и коротко.

Ассистент:

  1. получает список непрочитанных диалогов;
  2. читает переписку в каждом и называет человека по имени;
  3. по каждому диалогу пишет коротко: кто, что хочет, черновик ответа; похожие вопросы группирует;
  4. ждёт вашего решения: отправить как есть, поправить или пропустить;
  5. отправляет одобренные ответы от имени сообщества и отмечает диалоги прочитанными.

Для этого в сервере есть готовый сценарий community_inbox — в Claude Desktop он появляется в списке промптов, остаётся выбрать его и указать тон ответов.

Инструменты

ИнструментЧто делает
vk_messages_get_conversationsДиалоги сообщества, новые сверху. Фильтр unread — то, что ждёт ответа; есть ещё «без ответа» и «важные»
vk_messages_get_historyПереписка в одном диалоге
vk_messages_sendОтвет от имени сообщества. Помечен как запись — клиент спросит подтверждение
vk_messages_mark_as_readОтметить диалог прочитанным

Что нужно

  • Токен сообщества с правом messages: Управление → Работа с API → Ключи доступа → Создать ключ.
  • Включённые сообщения в настройках сообщества.
  • Клиент с поддержкой MCP: Claude Desktop, Claude Code, Cursor, VS Code и другие. Как подключить — на главной.

Ограничения ВКонтакте

  • Сообщество может написать только тому, кто написал первым или разрешил сообщения от сообщества. Иначе ВКонтакте вернёт ошибку 901, и ассистент так и скажет.
  • Если ВКонтакте попросит подождать из-за частых запросов, сервер повторит отправку сам. Дважды сообщение не уйдёт: у каждого ответа свой random_id, и повтор с тем же номером ВКонтакте отбрасывает.

Безопасность

Сервер работает у вас на компьютере. Токен сообщества хранится в настройках вашего клиента и уходит только в API ВКонтакте. Отправка сообщения — действие, которое клиент подтверждает у вас; в сценарии community_inbox ассистенту прямо сказано не отправлять ничего, что вы не видели.
